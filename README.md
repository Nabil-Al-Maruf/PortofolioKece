# 🚀 Nabil Al Ma'ruf — AI Engineer & Tech Influencer Portfolio

Welcome to the official repository of **Muhammad Nabil Al Ma'ruf** — Founder of **EmmeDigital**, Information Systems Student at UIN Sunan Ampel Surabaya, AI Engineer, and Tech Content Creator.

This project is a state-of-the-art interactive web portfolio featuring an **HTML5 240-Frame Canvas 3D Scroll Animation**, dual-language support (**Indonesian 🇮🇩 / English 🇬🇧**), modal project showcases, and a responsive clean dark UI design.

---

## ✨ Key Features

- **🎬 240-Frame HTML5 Canvas Scroll Engine**: Ultra-smooth LERP-interpolated video frame rendering synchronized with document scroll progression.
- **🌐 Dual Language Switcher (ID / EN)**: Instant one-click language translation toggle between Bahasa Indonesia & English with `localStorage` memory persistence.
- **📂 7 Authentic Projects Showcase**: Detailed interactive modals featuring real mobile apps, full-stack web platforms, PWA systems, POS applications, and AI integrations.
- **🖼️ Lightbox Image Gallery**: Interactive thumbnail switcher and full-screen HD screenshot lightbox modal (`zoom-in` / `zoom-out`).
- **📱 100% Mobile & Tablet Responsive**: Customized breakpoint layouts optimized for smartphones, tablets, and desktop displays.
- **🎯 Clean Dark UI Aesthetics**: Professional contrast backdrop shadows, glassmorphism overlays, and zero artificial neon clutter.

---

## 🛠️ Tech Stack & Technologies

- **Frontend Core**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Graphics & Animation**: HTML5 Canvas 2D Context API, RequestAnimationFrame LERP Loop
- **Styling Design System**: Modern Glassmorphism, CSS Grid, Flexbox, Custom Breakpoints
- **Typography & Icons**: Google Fonts (*Outfit, Bebas Neue, Permanent Marker*), FontAwesome 6
- **Developer Tech Stack**: Python, AI Agentic Systems, Prompting, Kotlin, Jetpack Compose, Supabase, MySQL, SQLite, Node.js, CapCut.

## 🚀 Quick Start / Local Deployment

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Nabil-Al-Maruf/portofolio-website.git
   ```

2. **Serve Locally**:
   Run any static HTTP server inside the project folder:
   ```bash
   python -m http.server 8080
   ```

3. **Open in Browser**:
   Navigate to `http://localhost:8080` in your favorite web browser.
